## 2. Phase 2 範圍（七個工作流 W0–W6）

依原路線圖，Phase 2 =「玩法深度」（P4、P6、P8＋U4、U7），本版整合 Phaser 能力盤點後擴充「表現力」兩流（W5 氛圍層、W6 素材層）。以下依現有程式碼接口重新定義，並前置一個收尾工作流。

### W0 Phase 1 收尾與地基（帳本遺留一次清）

1. **歇腳符規則放寬**：`daily.ts` 目前「符不足→符歸零＋連勝減半」改為**保留剩餘符**、僅連勝減半+1（更符合倫理紅線的「溫和」定調；一行＋測試）。
2. **runRound 持久化**：主線局數存 localStorage（key `rht.run.v1`），重新整理不歸零——本身就是留存機制（Zeigarnik：回來時看到「第 7 局」）。escaped/exhausted 不降局數（現行為即如此）。
3. 衛生批次：`stripBrackets` 抽到 `paint.ts`；轉場窗 resize 邊角加註解防護；帳本其餘 cosmetic 項。
4. **中文展示字體**（UI 報告 §3）：`FONTS` 分 `display`／`displayZh`（`"Noto Serif TC", "MingLiU", serif`），由 `i18n.locale()` 選用；標題類文字全部改走 helper。零成本、不打包字型。
- 估 1.5 天。

### W1 生物個性化線索行為（P4）＋研究度第三里程碑

每種生物一條「判讀個性」——**只調 `generateLevel` 的參數，不加新線索型別**，語意可被玩家歸納：

| 生物 | 個性（生成參數修飾） | 玩家可歸納的敘事 |
|---|---|---|
| 霧絨鹿 mistfawn | 氣味容差 ×2 | 氣味淡薄，環帶更寬 |
| 燼棘獸 emberquill | 擾動半徑 −1（下限 1） | 行動謹慎，擾動範圍更準 |
| 織叢雀 thicketloom | 足跡錐半角 ×0.5 | 直線移動，方向精確 |
| 露躍獸 dewhopper | 補給點 +2 | 牠出沒處露水豐沛 |
| 紗霧蛾 veilmoth | 干擾線索 +1（僅 tier≥2） | 鱗粉迷惑感官 |
| 燈籽獸 lanternshrew | 線索距離範圍 −（min−1/max−2，下限 2/4） | 不走遠，線索圈收攏 |
| 稜脊獸 ridgecrest | 地形權重 rock ×3 | 出沒局岩坡遍布（配合牠 rock 偏好） |
| 羽尾獸 plumetail | 線索距離範圍 +（min+1/max+2） | 孢子飄得遠 |

- 實作落點：`src/data/creatures.ts` 加雙語 `quirkHint` 欄位；`src/core/generate.ts` 加 `applyQuirk(params, creatureId)` 純函式（可測試：每種生物跨種子驗證參數效果）；規則**不明示**，靠多局歸納。
- **研究度第三里程碑** `MILESTONE_QUIRK = 15`：達標後圖鑑該生物顯示 quirkHint（U5 研究度條上限從 8 → 15、第三刻度）。既有 3/8 里程碑不動；存檔 schema 不變（research 是數字，向前相容）。
- 求解性保證不變：反向錨定在參數修飾**之後**執行，交集收斂檢查照舊。
- 估 3 天（含 property 測試與平衡）。

### W2 道具系統（P6）＋資訊層（U4）

**道具（跨局持久，存 `rht.tools.v1`）：**
- **風向石**：解鎖條件「總收錄數 ≥5」。持有後氣味線索生成時 `windBiasNeeded: true` 並附 `biasDirection`；渲染從整環改為**偏心弧**（環上以 bias 方向為中心的 240° 弧），縮小推理範圍。落點：`generate.ts`（bias 由 rng 從真實方位 ±60° 內取）、`MapScene.drawClueOverlay` scent 分支。
- **微光鈴**：解鎖條件「任一金級記錄」。每局一次，HUD 鈕觸發，隨機標示一個干擾線索（橘 X 蓋在 token 上）；tier 1 無干擾時鈕停用。此即規格書 §10.2「排除干擾」rewarded-ad 掛載點的免費版——未來接 SDK 時同一函式加一個入口。
- 解鎖演出：結算畫面達成時插入「獲得道具」卡（一次性）。

**U4 資訊層：**
- 地形成本可見化：桌面 hover 格顯示高亮＋角標 `1`/`2`；HUD 迷你圖例（四色塊＋成本，compact 模式收為點擊「?」內容）。
- 已判讀線索 token 加金色小勾。
- `hud.hint` 於完成 3 局後自動隱藏（局數統計掛在 W0 的 `rht.run.v1`）。
- 估合計 3 天。

### W3 委託板（P8）＋營地擴充（U2 完整版）

- **委託生成**：以 `dailySeed` 派生（`mulberry32(dailySeed*31+k)`）每日輪替 3 則，全球相同。委託型別（判別聯集，純邏輯可測）：
  - `record-creature`：記錄指定生物（可加地形條件）
  - `stamina-finish`：剩餘體力 ≥N 完成一局
  - `quality-any`：以指定品質記錄任一生物
  - `daily-clear`：完成今日行蹤
- **完成判定**：Result 記帳區塊內以本局 `SessionState`＋結果評估；獎勵＝筆記碎片（指定生物或玩家最低研究度生物）×2–3。進度存 `rht.commissions.v1`（date key＋完成旗標）。
- **營地 UI**：三張委託小卡（標題／進度勾／獎勵圖示），放於每日卡下方；完成時卡片蓋勾演出。
- 心理學：Zeigarnik 三鉤完備（連勝＋委託＋圖鑑缺口全數在營地第一眼）。
- 估 2.5 天。

### W4 互動式新手引導（U7）

- 首局（`rht.help.v1` 未設時）改腳本化引導，取代 7 條圖例彈窗：
  1. 高亮最近線索 token＋「走過去看看」浮層
  2. 揭示演出後一句解讀（依線索型別）
  3. 第二條揭示後：短暫高亮交集區**一次**（僅首局；不違反「UI 不強制提示正解」）
  4. 逼近前一行 QTE 預告
- Help 彈窗保留為手冊。實作落點：`MapScene` 輕量狀態機＋`fx.ts` 高亮 helper；文案全部走 i18n。
- 估 2 天。

### W5 氛圍層（Phaser 第二梯隊：粒子＋postFX＋輕音效）

**低密度氛圍粒子**（Phaser 內建 ParticleEmitter；修訂原「不做粒子雨」約束——見 §6）：
- 地圖霧氣：mist 地形格上緣 1 個 emitter、同時存活 ≤20 顆、大顆低透明度慢飄——水墨暈染的動態延伸，非「粒子雨」。
- 收錄成功：結算肖像處一次性孢子飄落（≤30 顆、2 秒自滅）——峰終之「峰」的加固。
- 營地營火：火星上飄（≤8 顆）——營地唯一的動態元素，替代原靜態妥協。
- 邊界：`prefers-reduced-motion` 時全部停用；粒子總數上限寫成常數集中管理；低階裝置（fps 監測 <40 持續 3 秒）自動關閉。

**postFX（Phaser 3.60+ 內建，WebGL 限定）：**
- QTE 發光弧改用真 bloom（`postFX.addGlow`），取代現在的「寬幅低透明度多畫一圈」；生物剪影發光細節同理。
- **Canvas fallback 必須保留**：`renderer.type` 檢測，非 WebGL 時沿用現行疊圈畫法（現行程式碼即 fallback，零額外成本）。

**輕音效八件套**（提前自 Phase 3；U3 表原本就標了「輕音效」）：
- 環境風聲循環（營地＋地圖，音量極低）、線索揭示、補給拾取、QTE 命中／失手、收錄成功、逃逸、按鈕點擊。
- 來源：免費音效庫或程序生成（WebAudio 合成——零素材檔案），首選後者維持零成本零體積；首次互動後才 unlock AudioContext（portal 平台規範）；HUD 加靜音切換（記憶於 `rht.audio.v1`）。
- 估合計 3 天。

### W6 素材層（規格書 Day 7–10：AI 生成素材替換）

視覺跳最大的一步，與引擎無關。獨立成流、可與 W1–W4 並行由人類主導生成與審查：
- **範圍**：8 生物 sprite（取代程式剪影）、四種地形紋理貼圖（取代色塊）、UI 圖標（羅盤／腳印／體力）。
- **流程**：AI 生成概念圖 → 人工簡化為 sprite → **人工複查內容邊界**（規格書 §2：不得與真實動物／族群符號／宗教圖騰產生視覺聯想）→ 打包。
- **技術約束**：走 npm bundle（不用 CDN）；spritesheet 合併控制請求數；**體積預算：初始下載 ≤50MB（CrazyGames Basic）、單張生物 sprite ≤64KB**，為 Poki 8MB 保留分包空間；剪影版程式碼保留為載入失敗 fallback。
- 素材未到位前 W1–W5 全部可先行——介面以貼圖 key 為界（`sil-<id>` 慣例延續）。
- 估：工程整合 2 天（素材生成與審查為人類側工作，不計入）。

### Phase 3 預告（本提案僅定方向，屆時另出設計細節）

P7 天氣（與 W1 個性修飾**乘法疊加**，順序：base → quirk → weather；天氣粒子表現直接複用 W5 的 emitter 架構）→ P9 異彩變種（5% 機率、`Palette` 加 `iris` 色、圖鑑星位——U5 已預留；發光表現複用 W5 postFX）→ P5 押注續追（計分草案：收錄分 = 局數×100×品質係數 1/1.2/1.5；押注 ×1.5→×2→×2.5 封頂；為排行榜鋪路）→ P10 微事件 → 音效擴充（音樂／更多環境層）。

## 3. 設計決策（需核准）

| # | 決策 | 建議 | 理由 |
|---|---|---|---|
| D1 | 歇腳符不足時是否沒收剩餘符 | **保留剩餘符**，僅連勝減半 | 「降級不歸零」的精神延伸；沒收＋減半是雙重懲罰 |
| D2 | runRound 是否持久化 | **是**（`rht.run.v1`） | 回訪看到累積局數是廉價的 Zeigarnik 鉤 |
| D3 | 個性提示解鎖點 | **新增 MILESTONE_QUIRK=15** | 3/8 已各司其職；15 給重度玩家長線目標 |
| D4 | 風向石／微光鈴解鎖條件 | 總收錄 ≥5／任一金級 | 前者自然達成、後者與 P3 精熟目標掛鉤 |
| D5 | 委託是否全球同題 | **是**（dailySeed 派生） | 與每日挑戰同語言，未來可比較 |
| D6 | 每日挑戰是否套用生物個性 | **是**（同種子=同個性，公平） | 個性是核心深度，不套用會讓每日變淺 |
| D7 | 是否修訂「不做粒子雨」約束 | **修訂為「不做高密度粒子；低密度氛圍粒子允許」**（總量上限常數化＋reduced-motion／低幀自動停用） | 原約束的三個理由（家庭向／低階效能／水墨留白）以邊界條件保住，換取氛圍層 |
| D8 | postFX 是否強制 | **否**——WebGL 才啟用，Canvas 沿用現行疊圈畫法 | itch.io/舊裝置相容；現行程式即現成 fallback |
| D9 | 音效來源 | **首選 WebAudio 程序合成**（零檔案），不足處再補免費庫 | 零成本零體積，守 Poki 8MB 空間 |
| D10 | 素材替換是否進 Phase 2 | **工程整合進（W6）**，素材生成與內容審查由人類並行主導 | 生成/審查非工程節奏，解耦後互不阻塞 |

## 5. 明確不做（承襲並修訂）

不引入 DOM 疊層、不打包字型檔、不做小地圖／自動尋路、不做倒數 FOMO／付費捷徑。**修訂**：「不做常駐循環動畫與粒子雨」放寬為「不做高密度粒子與騷動式循環動畫；低密度氛圍粒子與呼吸式狀態指示允許，總量常數化＋reduced-motion／低幀自動停用」（D7）。「不加外部素材」隨 W6 廢止，改為**體積預算制**（§2 W6）。
