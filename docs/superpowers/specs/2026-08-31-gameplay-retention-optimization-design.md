# Ridge Hunter's Trail — 遊戲性豐富化與黏著度優化提案 v1.0

> 狀態：**提案待審**。本文件為設計提案（非實作計畫），經核准後再依 superpowers:writing-plans 拆解為實作計畫。
> 依據：規格書 v1.1、MVP 實作現況（commit b6729f8）、2025–2026 同類型熱門遊戲市場研究。

---

## 1. 現況盤點

### 已完成（MVP）
- 核心迴圈：線索推理（足跡錐／擾動圓／氣味環＋干擾線索）→ 體力移動 → 轉盤 QTE → 圖鑑收錄 → 難度遞增（3 tier）。
- 8 種原創生物（雙語）、圖鑑存檔（localStorage）、標記系統、補給道具、en/zh-TW 多語系、水墨風佔位美術與剪影貼圖。
- 架構優勢：純邏輯層可測試、**種子 RNG（mulberry32）已就位**、`windBiasNeeded` 欄位已預留、數值集中於 `difficulty.ts`。

### 目前的黏著度缺口
| 缺口 | 影響 |
|---|---|
| 單局結束後沒有任何跨局累積（除圖鑑計數） | 無長線目標，D1 留存無抓手 |
| 失敗＝整局清空重來（escaped/exhausted） | 懲罰過重且**零進度感**，最易導致流失的時刻 |
| 圖鑑只有「收錄次數」一個維度 | 收集深度不足，8 種很快集滿 |
| 8 種生物玩法上無差異（僅地形偏好） | 中期體驗同質化 |
| 無每日回訪理由 | portal 演算法最重視的回訪指標缺位 |
| 移動階段（迴圈中段）缺乏事件 | 走格子的過程平淡 |

## 2. 同類型熱門遊戲對照（2025–2026）

| 參考對象 | 關鍵機制 | 可轉譯到本作的點 |
|---|---|---|
| **Clues by Sam**（2025 上線，2026 初 5 萬 DAU）、Wordle、NYT Games | 每日一題、全球同題、emoji 成績分享、連勝紀錄 | 種子 RNG 以日期為種子＝零成本每日挑戰；分享卡 |
| **Neko Atsume / New Pokémon Snap / Alba** | 收集迴圈、記錄「品質分級」（星級照片）、圖鑑條目本身是獎勵 | QTE 表現 → 記錄品質（銅/銀/金）；圖鑑條目逐步揭示 |
| **Slay the Spire / Hades / 各 roguelite** | 失敗仍有 meta 進度（failure-with-progress） | 逃逸/力竭改為掉落「觀察筆記」碎片，累積圖鑑研究度 |
| **Obra Dinn / Golden Idol / Outer Wilds** | 「知識即進度」——玩家學到的判讀規則本身是成長 | 生物個性化線索行為，靠多局觀察歸納 |
| **CrazyGames/Poki 官方指引** | 3 分鐘內上手、10+ 分鐘平均時長、D1 10–15%、每日鉤子 | 首局引導、委託任務延長時長、每日挑戰拉回訪 |

## 3. 優化提案

### A 組：黏著度機制（心理學驅動）

**P1 每日挑戰＋分享卡**（規格書 §10.3 的具體化）
- 以 UTC 日期為種子（`mulberry32(yyyymmdd)`）生成全球同題；固定為 tier 2 難度、獨立於主線進度。
- 結算產出 emoji 成績卡（步數／體力餘量／記錄品質），一鍵複製，格式仿 Wordle 網格。
- 連勝（streak）計數＋**溫和保護**：每 7 天連勝發 1 枚「歇腳符」，漏一天自動抵扣，不歸零。
- 心理學：預約機制（appointment mechanics）、社會證明（分享卡）、損失趨避（連勝）但以家庭向方式軟化、fresh start effect（每天新題）。
- 依託：種子 RNG 已就位，估 1–2 天。

**P2 失敗軟著陸：觀察筆記碎片**
- `escaped` / `exhausted` 不再一無所獲：依本局已判讀線索數掉落 1–3 枚該生物的「觀察筆記」。
- 每種生物圖鑑增加「研究度」進度條（筆記＋成功記錄都累積）；研究度里程碑解鎖：描述段落 → 個性線索提示（見 P4）→ 完整插畫。
- 心理學：Zeigarnik 效應（未完成的進度條）、endowed progress（首次遭遇即預填一段研究度）、roguelite 式 failure-with-progress 消解「整局白玩」的挫折。
- 依託：擴充 `codex.ts` 存檔 schema（v2 遷移），估 2 天。

**P3 記錄品質分級（銅／銀／金）**
- QTE 命中數決定品質：達標＝銅、全中＝金、介於＝銀；圖鑑顯示每種生物的最佳品質。
- 金級是圖鑑「完美收藏」條件 → 已集滿的玩家仍有重玩理由。
- 心理學：精熟需求（SDT 的 competence）、goal gradient（差一級就想再試）、峰終定律（結算畫面以品質揭曉作為情緒高點）。
- 依託：`qte.ts` 已回傳命中數，估 1 天。

**P4 生物個性化線索行為（知識即進度）**
- 每種生物 1 條「判讀個性」，例：霧絨鹿的氣味環在霧地形上容差加倍；稜脊獸足跡成對出現且互為鏡像；紗霧蛾的擾動圓每局偏小。
- 不明示規則——玩家靠多局觀察歸納，或用 P2 研究度解鎖提示。
- 心理學：Obra Dinn／Outer Wilds 式「玩家腦中的知識」是最強的內在動機進度；同時讓 8 種生物玩起來真的不同。
- 依託：`generate.ts` 依 creatureId 調參，估 2–3 天（含平衡）。

**P5 押注續追（push-your-luck run 模式）**
- 成功記錄後結算畫面給選擇：「安全歇腳」（積分入袋）或「乘勝續追」（下一局積分 ×1.5、×2…；逃逸則失去未入袋的加成，已入袋不動）。
- 產出單一「最佳連追」分數，為未來排行榜／每日挑戰比分鋪路。
- 心理學：損失趨避的正向運用（保住 vs 翻倍的張力）、autonomy（玩家自選風險）。
- 估 2 天。

### B 組：遊戲性豐富化

**P6 風向石道具**（啟用預留的 `windBiasNeeded`）
- 研究度或圖鑑里程碑解鎖；持有後氣味線索附帶方向偏移資訊（環 → 偏心弧）。
- 另一道具「微光鈴」：一局一次，標示出一個干擾線索——同時就是規格書 §10.2 排除干擾的 rewarded-ad 掛載點的免費版本。
- 心理學：解鎖期待、稟賦效應（自己的工具箱）。估 2 天。

**P7 天氣系統**
- 每局隨機天氣（晴／霧／風／細雨）調整線索參數：霧日氣味容差放寬但足跡錐加寬、風日氣味失準但擾動半徑縮小等。
- 讓同 tier 的局與局之間有變化；每日挑戰的天氣成為當日話題點。
- 估 2 天。

**P8 委託任務板**
- 主選單常駐 3 則輪替委託：「在霧地形記錄紗霧蛾」「剩餘體力 ≥20 完成一局」「金級記錄任一生物」；完成給筆記碎片或道具。
- 心理學：明確短期目標（Zeigarnik）、拉長單次遊玩時長（portal 指標）。估 2 天。

**P9 稀有變種（閃色）**
- 每局約 5% 機率目標為「異彩變種」（獨立配色＋圖鑑獨立欄位）；QTE 前的接近動畫先揭示，製造驚喜瞬間。
- 心理學：變動比率增強（variable-ratio reinforcement）——最強的回訪驅力；以純遊玩獎勵實現，無任何抽卡／付費，守住 PEGI 定位。估 1–2 天。

**P10 途中微事件**
- 移動時低機率觸發：驚起鳥群（指向目標的粗方向）、拾獲多餘補給、發現舊足跡（一次性弱線索）。
- 填補迴圈中段的平淡，讓「走路」也有期待感。估 1–2 天。

## 4. 心理學原理對照表

| 原理 | 對應提案 | 出處脈絡 |
|---|---|---|
| 變動比率增強（Skinner） | P9 變種、P10 微事件 | 不可預期獎勵產生最持久的行為 |
| 損失趨避（Kahneman & Tversky） | P1 連勝、P5 押注 | 家庭向軟化：歇腳符、已入袋不罰 |
| Zeigarnik 效應／目標梯度 | P2 研究度、P3 品質、P8 委託 | 未完成進度條與「就差一點」 |
| Endowed progress | P2 首遇預填研究度 | 有起頭的進度條完成率更高 |
| 自我決定理論（SDT） | P3 精熟、P5 自主、P1 分享（連結感） | 內在動機三要素全覆蓋 |
| 心流（Csikszentmihalyi） | P4/P7 難度變化、QTE 曲線 | 挑戰與技能匹配 |
| 峰終定律 | P3 品質揭曉、圖鑑收錄動畫 | 結算是記憶錨點 |
| 預約機制／fresh start | P1 每日挑戰 | 每天一次的乾淨開局 |

**倫理紅線**（PEGI 3–7 與規格書 §10.5 一致）：不做倒數計時 FOMO、不做付費捷徑、連勝斷了不清零只降級、所有機率獎勵純遊玩取得。

## 5. 分階段路線圖

| 階段 | 內容 | 估時 | 驗證指標 |
|---|---|---|---|
| **Phase 1 黏著基礎** | P2 失敗軟著陸 → P3 記錄品質 → P1 每日挑戰＋分享卡 | 約 1 週 | D1 留存、每日挑戰參與率 |
| **Phase 2 玩法深度** | P4 生物個性 → P6 風向石／微光鈴 → P8 委託板 | 約 1–1.5 週 | 平均時長 ≥10 分、圖鑑研究度分佈 |
| **Phase 3 長線內容** | P7 天氣 → P9 變種 → P5 押注續追 → 音效與結算演出 | 約 1–1.5 週 | 回訪頻率、單日多局率 |

排序理由：P2 先行——它改動失敗體驗這個最大流失點，且 P1/P3/P8 的獎勵都以「筆記碎片／研究度」為貨幣，先立貨幣再接水管。每階段結束都是可上架的完整版本，符合 itch.io → CrazyGames 的驗證節奏，rewarded-ad 掛載點（§10.2）與 P2/P6 天然對齊。
