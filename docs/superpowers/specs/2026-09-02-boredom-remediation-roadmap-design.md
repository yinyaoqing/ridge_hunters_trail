## 1. 分階段的依據

診斷的七個重寫彼此有硬相依，不能依「嚴重度」排序施工：

```
R3 判讀工具 ──┬─→ R4 接近取代轉盤
R5 全揭曉  ──┘      ↑
                     │
R2 地貌與尋路 ──→ R1 活的獵物 ──┘
                     │
                     └─→ R6 生態系 ──→ R7 山域
```

- **R5 的揭曉要比對「玩家的押注格」與真實位置** → 必須先有 R3 的押注標記。兩者綁在同一階段。
- **R1 的獵物移動模式（沿水線、只走岩坡）需要有結構的地形** → R2 必須在 R1 之前。
- **R4 的成功率取決於判讀精準度、驚動值、風向遮蔽** → 需要 R3（精準度）＋ R1（驚動值）＋ R2（遮蔽）全部就位。
- **R6/R7 是容器**：山域決定物種、天氣、地形與線索型別，必須最後做。

依此得到的施工序，同時也讓「每單位改動解除的無聊量」由高到低排列：

| 階段 | 代號 | 交付 | 主要解除 |
|---|---|---|---|
| Phase 4 | 判讀與揭曉 | R3 ＋ R5 ＋ A-07 | B-01 B-02(部分) B-03(部分) C-03 D-01 D-02 D-04 D-05(部分) A-07 |
| Phase 5 | 有地方的山 | R2 | A-01 A-02 A-03 A-04 A-05 A-06 |
| Phase 6 | 活的獵物 | R1 | B-02 B-03 B-04 C-01(部分) D-02 |
| Phase 7 | 接近取代轉盤 | R4 | C-01 C-02 C-03 C-04 B-05(部分) |
| Phase 8 | 生態系與山域 | R6 ＋ R7 | B-05 B-06 D-03 E-01 E-02 E-03 E-04 E-05 E-06 |

28 個發現全數被覆蓋，無遺留。

## 2. 全域約束（每個階段都適用）

沿用專案既有規範，各階段計畫的 Global Constraints 直接複製本節：

- **技術棧不變**：Phaser 3.90 ＋ TypeScript strict ＋ Vite ＋ Vitest。不新增任何 runtime 相依。
- **測試邊界**：`vite.config.ts` 的 `test.environment` 為 `node`，場景（Phaser）無法單元測試。
  **所有新邏輯一律抽成 `src/core/` 的純函式並 TDD**；場景層只做接線，以 `npm run build`
  （＝`tsc --noEmit && vite build`）＋ 人工冒煙驗證把關。
- **多語系**：所有面向玩家的字串走 `i18n.t()`，`en` 與 `zh-TW` 兩份同步新增，不得硬編字面值。
- **可解性不可破壞**：反向錨定（線索一律由目標／幌子點反推）為不可退讓的地基，任何新線索型別
  都必須以同一手法生成。
- **無傷害定位**：不得出現死亡、流血、傷害。失敗一律是「牠溜走了」。
- **線索金光恆定**：`CLUE_GOLD = 0xd8c874` 跨三套配色不變；任何新增顏色不得與其相近，
  避免被誤讀為線索。
- **世界觀完全虛構**：不得引用任何真實文化紋樣、族群、地名、宗教符號。
- **體積門檻**：`dist` 初始下載 ≤ 8MB（Poki 最嚴標準，目前 1.5MB）。
- **新增儲存鍵必須同步** `docs/ARCHITECTURE-NOTES.md` 的兩張表（localStorage／registry），
  落地當下就補，不得延後。

## 3. 各階段範圍

### Phase 4 — 判讀與揭曉

**主張**：先讓玩家能表達推論、並且每一局都學到東西。這是唯一不需要改動關卡生成模型的階段，
因此最先做。

- **三態標記**：`marks` 由 `Set<string>` 升級為 `Map<string, MarkKind>`，三態循環
  排除（紅 ✕）→ 存疑（黃 ?）→ 押注（金 ◎）→ 無。押注格全域唯一。
- **候選熱區圖層**：可開關的覆蓋層，以濃淡顯示每格符合幾條已判讀線索。`intersect()` 從
  引導專用升格為玩家工具。
- **線索靜音**：對已判讀的線索格再次標記即可把它排除在熱區計算之外，直接看見
  「如果這條是假的，答案會落在哪」——把 B-03 的多數決換成假說檢驗。
- **判讀精準度成為評分軸**：銅／銀／金改由「押注格與真實位置的 Chebyshev 距離」決定
  （0＝金、≤2＝銀、其餘＝銅），`qualityFromQte` 移除。QTE 本階段仍決定成敗，但不再決定品質。
- **全揭曉（新場景 `RevealScene`）**：不論成敗，QTE／力竭之後一律先進揭曉畫面再進結算，
  顯示真實位置、玩家路徑、押注格與距離、誤導你的那條幌子、以及「資訊在第幾步就已完備」。

**不做**：不動關卡生成、不動地形、不動獵物、不動 QTE 成敗判定。

**驗證指標**：失敗後點「重新追蹤」的比例；單局平均押注標記使用率。

### Phase 5 — 有地方的山

**主張**：把探索段的四十次無決策點擊換成六次路線決策，並讓地圖第一次有「地方」。

- **地形改用雜訊生成真實地貌**：稜線、溪谷、林線、開闊草坡、裸岩區，取代逐格獨立
  `pickWeighted`。以種子化 value noise 實作，維持 daily 的決定性。
- **地形成本拉開層次**：1 / 2 / 4 / 不可通行，讓繞路值得計算。
- **視野與線索顯形**：線索 token 只在進入視野半徑後才顯示；高地給視野加成、密叢遮蔽。
- **主動「駐足觀察」**：花體力在原地掃描一圈，把體力從純計時器變成可分配資源。
- **點擊目的地自動尋路**：A\* 於成本網格上求解，確認前預覽總體力成本與行經地形。

**相依**：無（可與 Phase 4 並行，但排在其後以免同時改動 MapScene 造成衝突）。

**驗證指標**：單局點擊數中位數（目標從 30+ 降到 10 以下）；單局時長不變或略降。

### Phase 6 — 活的獵物

**主張**：把 `targetPos` 從常數改成有狀態的行為體。這是「狩獵」二字唯一的兌現方式。

- **獵物會動**：每 N 步沿覓食路線移動一次，移動模式依物種而異（沿水線／只走岩坡／會折返），
  路線受 Phase 5 的地形結構約束。
- **線索有新鮮度**：`Clue` 新增 `age` 欄位（今晨／昨夜／更早），視覺上以濃淡區分。
  幌子線索的新鮮度會與真線索矛盾——干擾第一次可以被推理排除，而非數量投票。
- **驚動值**：靠太近、走過岩坡、逆風接近都會累加；滿了獵物換位並留下一組「慌亂痕跡」，
  對玩家而言既是失敗也是新情報。
- **物種個性從參數改為行為**：`applyQuirk` 的不可感知乘法退場，改為可觀察、可學習、可預測的
  移動與留痕規則。

**相依**：Phase 5（地形結構）。

**驗證指標**：單局內玩家改變判斷的次數；同一物種第二次遭遇的成功率提升幅度。

### Phase 7 — 接近取代轉盤

**主張**：讓結尾成為這場狩獵的結論，而不是一次抽獎。

- **潛行決策序列取代 QTE**：最後三格改為「從哪個方位切入（風向）／要不要走遮蔽繞路／
  要不要屏息換一回合靜音移動」的一次性決策。
- **成功率由本局實際條件決定**：判讀精準度（Phase 4）、驚動值（Phase 6）、風向、遮蔽
  （Phase 5）、剩餘體力。保留一次呼吸節奏收尾作為手感，但它只微調結果。
- **失敗改為部分成功**：牠受驚逃走，但玩家取得一張模糊的照片與逃逸方向——這一局仍推進圖鑑，
  下一局帶著情報開始。C-02 的挫折炸彈由此拆除。
- **異彩變種提前揭曉**：追蹤中期即以虹光鱗粉／異色羽等特殊線索暗示，讓玩家有機會為牠改變策略。

**相依**：Phase 4（精準度）、Phase 5（遮蔽）、Phase 6（驚動值、風向反應）。

**驗證指標**：QTE 移除後的單局完成率；玩家在最後三格改變路線的比例。

### Phase 8 — 生態系與山域

**主張**：給長線內容一個終點與一個循環，並讓玩家的意圖第一次能對上遊戲的獎勵。

- **山域制**：一片山域＝一段 5–7 局的旅程，有固定主題、專屬物種、專屬地形，
  結尾是一次「稀有目擊」壓軸；完成後解鎖下一片。取代 `getDifficulty` 在第 8 局封頂的無盡遞增。
- **每片山域引入一個新的線索型別**：回聲、水痕、夜視、羽落、體溫殘留。難度來自新的判讀語彙，
  而不是更大的地圖。
- **路線選擇取代隨機指派**：營地提供三條今日山徑，各自標示地形、天氣與可能的目擊物種。
  E-02 由此消失，委託終於可以被主動完成。
- **出沒條件與物種互動**：特定天氣／時段／地形才出現；追一隻會驚動另一隻；捕食者出現時
  獵物全部躲起來。天氣成為出發前的決策。
- **道具改為出發前三選一**，互相排斥，把永久增益換成每局取捨。
- **圖鑑獎勵改為能力**：完整研究一隻生物後解鎖針對牠的判讀技能（如看出足跡新鮮度），
  取代一次性描述文字。
- **每日挑戰給出比較對象**：今日 par 步數、全球平均判讀精準度，以及一張洩露推理過程的方格圖
  （每步一格，顏色表示該步是否縮小了候選集合）。
- **營地隨進度長大**：標本牆、逐片點亮的區域地圖、隨季節換色的天空。

**相依**：Phase 4–7 全部。

**驗證指標**：次日回訪率；分享卡貼出率；圖鑑完成度分布。

## 4. 明確保留（不得為了張力犧牲）

診斷書「這些請留著」四項，列為各階段的驗收否決條件：

1. **反向錨定生成** — 每一關數學上必定有解、不需事後驗證。新線索型別必須沿用同一手法。
2. **無傷害的定位** — 失敗只是「牠溜走了」。這是分級與平台過審的護城河。
3. **失敗軟著陸** — 失敗仍給觀察筆記、仍推進研究度。Phase 4 只把「進度條」升級為「知識」，
   不移除軟著陸本身。
4. **線索金光的一致性** — `CLUE_GOLD` 跨配色恆定，判讀性不受配色影響。
